# AI usage

The assignment asks for an honest account of where AI was used. This log is
appended to as work proceeds.

## Tooling

- **Claude Code (Opus 5)** — used as the primary implementation tool, driven
  phase by phase against `docs/PLAN.md`. Each phase was scoped, reviewed and
  approved by hand before implementation.
- **Claude (web)** — used beforehand to turn the assignment brief into
  `CLAUDE.md` (project rules) and `docs/PLAN.md` (phased plan).

## How it was used

- Project rules and the phased plan were written first, then held as the
  contract for every subsequent prompt. Scope expansion was pushed to an
  "Open questions" section rather than implemented on the spot.
- Package versions were resolved against the npm registry at scaffold time
  rather than from model memory, since these drift quickly.
- Scaffolding was generated by the official CLIs (`create-next-app`,
  `@nestjs/cli`, `shadcn`) rather than hand-written, then trimmed: generated
  boilerplate controllers, sample pages, and duplicate config files were
  deleted.

## Per-phase log

### Phase 0 — Skeleton + deploy pipeline

- Scaffolded the pnpm workspace, NestJS API and Next.js frontend.
- Wrote the env loader, CORS configuration, `/health` endpoint and its tests,
  and the API-status page.
- Verified by hand: `/health` responds `{ ok: true }`; a CORS preflight from an
  allowed origin returns `Access-Control-Allow-Origin` while a foreign origin
  does not; the status page renders both the reachable and unreachable states.
- Correction made during review: the unreachable state initially surfaced
  Node's raw `fetch failed`, which violates the project's error-message rule.
  Replaced with a message that names the URL and the setting that controls it.
- Deployment to Railway and Vercel was carried out by hand, from a written
  checklist, so that credentials never entered an AI session. The one build
  failure (`pnpm: not found` on Railway) was diagnosed and fixed by hand in the
  Railway dashboard; the fix was afterwards written back into `railway.json`.
